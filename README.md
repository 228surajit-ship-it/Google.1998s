Google Homepage 1998

A recreation of the original Google homepage from 1998, bringing back the simple and classic design of the early days of Google.

📖 About the Project

This project recreates the appearance and basic experience of Google's original homepage from 1998. It focuses on the minimalist design, simple search layout, classic typography, and the early web experience.

The goal is to bring a piece of internet history back to life through HTML, CSS, and JavaScript.

✨ Features

- Classic 1998-inspired Google homepage design.
- Simple and clean interface.
- Traditional search box.
- Classic Google-style buttons.
- Minimalist layout and typography.
- Search functionality.
- Responsive webpage layout.
- Lightweight and easy-to-understand code.

🛠️ Technologies Used

- HTML5 – Creates the structure of the webpage.
- CSS3 – Controls the appearance, layout, and design.
- JavaScript – Adds interactive features and functionality.

📦 Installation

1. Download or clone this repository.
2. Open the project folder.
3. Locate "index.html".
4. Open it in your web browser.

No complicated installation process is required.

🚀 Deployment

This project can be deployed using GitHub Pages.

1. Open the repository on GitHub.
2. Go to Settings.
3. Select Pages.
4. Choose the deployment branch.
5. Save the settings.

GitHub will provide a website link after deployment.
